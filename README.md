## 🎯 What is ListingAI?

ListingAI is a **free AI-powered product listing generator** that helps Amazon, Etsy, and Shopify sellers create professional, SEO-optimized product listings in seconds.

**No signup required. No credit card. 100% free forever.**

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ installed
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/z-sops/listingai.git

# Navigate to project
cd listingai

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production

```bash
npm run build
```

The optimized files will be in the `dist` folder.

## 📦 Deployment

This project is optimized for **Vercel** deployment.

### Deploy to Vercel

1. Push your code to GitHub
2. Go to [vercel.com](https://vercel.com)
3. Import your repository
4. Click "Deploy"

That's it! Your site will be live in 2 minutes.

## 🎨 Customization

### Change Brand Colors

Edit `src/App.tsx` and search for `orange-500` to change the primary color.

### Add More Categories

In `src/App.tsx`, find the `categories` array and add your categories:

```typescript
const categories = [
  'Electronics & Gadgets',
  'Home & Kitchen',
  // Add more here...
];
```
